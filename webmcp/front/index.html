Introduction

기본 개념 이해하기

WebMCP와 AI 비서가 무엇인지, 어떻게 동작하는지 핵심 개념을 정리했습니다.

🧩
WebMCP란?

웹사이트용 AI 도구 연결 플랫폼

WebMCP는 Gemini 기반 AI 비서를 웹사이트에 안전하게 통합하기 위한 멀티테넌트 프록시 플랫폼입니다. Google이 제안한 웹 표준(MCP, Model Context Protocol)의 개념을 실무에 구현하여, 웹 페이지가 AI 에이전트에게 구조화된 도구를 노출하도록 돕습니다.

  • AI API 키를 클라이언트에 노출하지 않고 서버 DB에서만 관리
  • 도메인(고객사) 단위로 키·모델·호출 한도를 독립 운영
  • 표준 위젯 스크립트 3줄로 어떤 사이트에도 빠르게 적용
💬
AI 비서란?

사이트 지식을 답변하는 대화형 에이전트

AI 비서는 사이트에 주입된 지식(회사 소개, 제품, 서비스, 예약 등)을 바탕으로 사용자의 질문에 즉시 답변하는 대화형 챗봇입니다. WebMCP가 제공하는 위젯을 통해 우측 하단 버튼으로 열고, 빠른 메뉴(퀵 질문)나 자유 입력으로 이용할 수 있습니다.

  • 사이트별 시스템 프롬프트로 브랜드·도메인 지식을 주입
  • 퀵 메뉴로 자주 묻는 질문을 한 번의 클릭으로 제공
  • 24시간 무중단으로 고객 문의에 자동 응답
Why WebMCP

왜 WebMCP인가?

AI 비서를 도입하려는 기업이 마주치는 보안·운영·비용 문제를 한 번에 해결합니다.

🔒

키 노출 제로

Gemini API 키는 클라이언트에 전달되지 않고 서버 DB에서만 보관됩니다. 모든 호출은 프록시를 경유합니다.

🧩

도메인별 멀티테넌트

고객사마다 별도의 키와 모델, 호출 한도를 독립적으로 관리합니다. 새 고객 추가도 DB 한 줄이면 끝납니다.

🛡️

비정상 접속 감지

Origin·User-Agent 기반으로 비정상 요청을 차단하고, 모든 접속을 로깅해 이상 징후를 추적합니다.

⚡

원클릭 배포

표준 위젯 스크립트 세 줄만 붙이면 AI 비서가 완성됩니다. 코드 수정 없이 재사용 가능한 구조입니다.

🎨

사이트별 브랜딩

고객사마다 색상·퀵 메뉴·지식 프롬프트를 자유롭게 커스터마이즈해 브랜드 정체성을 유지합니다.

📈

운영 부담 최소화

도메인 단위 Rate Limit과 요청 로그로 과금·이상 사용을 한눈에 관리할 수 있습니다.

Use Cases

WebMCP의 활용

실제 비즈니스 현장에서 이렇게 쓰입니다.

1

병원·의료 사이트

진료과·의사·예약 정보를 AI가 안내하는 고객 상담 비서로 활용합니다.

2

제조·부품 기업

제품 스펙·솔루션·기술 문의를 AI가 답변해 영업·기술 문의를 자동화합니다.

3

서비스 플랫폼

서비스·가격·상담원 안내 등 고객 FAQ를 AI 비서가 24시간 처리합니다.

Value

WebMCP가 만드는 가치

도입 기업과 고객 모두에게 실질적인 성과를 제공합니다.

💰

고객 응대 비용 절감

반복적인 문의를 AI가 대신 처리해 상담 인력의 부담을 줄이고 응답 시간을 단축합니다.

🌙

24시간 무중단 서비스

시간과 관계없이 항상 답변하는 AI 비서로 고객 만족도와 전환율을 높입니다.

🚀

빠른 시장 출시

복잡한 AI 인프라 구축 없이 며칠 만에 AI 경험을 서비스에 통합할 수 있습니다.

🔐

규제·보안 리스크 감소

키 노출을 원천 차단하고 도메인 단위로 격리해 보안 감사에도 안심할 수 있습니다.

📊

데이터 기반 인사이트

요청 로그를 통해 고객이 무엇을 궁금해하는지 파악해 제품·콘텐츠 전략에 활용합니다.

♾️

확장 가능한 구조

고객사가 늘어나도 서버 한 대로 수십 개 사이트를 안정적으로 서빙할 수 있습니다.

Web Standard

웹 표준에 기반한 접근

WebMCP는 Google이 제안하는 웹 표준입니다. 이 플랫폼은 그 표준의 개념을 실무에 구현합니다.

📖

WebMCP(워크플로우 모델 컨텍스트 프로토콜)는 AI 에이전트를 위한 구조화된 도구를 빌드하고 노출하는 데 도움이 되는 제안된 웹 표준입니다(Chrome for Developers, 2026). JavaScript를 제공하고 HTML 폼 요소를 주석 처리하여 에이전트가 페이지 기능과 정확히 상호작용할 수 있도록 하며, 이를 통해 에이전트 동작의 성능과 안정성을 크게 개선합니다.

선언적 도구 정의

검색·구매 등 명시적 목적을 JSON 스키마로 선언해, 에이전트가 요소의 목적을 추측하는 대신 정확히 이해하도록 합니다.

인간 중심 인터페이스 보존

도구가 웹페이지에서 눈에 띄게 실행되어 사용자가 작업이 예상대로 완료된다는 신뢰를 얻고, 브랜드와 디자인을 그대로 유지합니다.

오리진 격리 & 권한 정책

도구 등록은 오리진 격리된 문서에서만 허용되고, 권한 정책으로 최상위·동일 오리진으로 제한해 보안을 강화합니다.
