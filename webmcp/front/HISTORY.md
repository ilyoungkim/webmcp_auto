# 변경 이력 (History) — webmcp/front

웹 위젯(`webmcp-widget.js`, `widget.css`, `widget.js`)의 버전별 변경 사항을 기록합니다.

## v1.1.0 (2026-08-22)

### ✨ 주요 변경 사항

#### 1. 🧠 대화 기억(Memory) 기능 추가 (`webmcp-widget.js`)
- **로컬스토리지 기반 대화 저장**
  - 질문-답변 쌍을 `localStorage`(`wmcpMemory` 키)에 저장하여 새로고침/재접속 후에도 유지됩니다.
  - 최대 50개 대화 쌍을 보관하며, 초과 시 오래된 것부터 자동 제거됩니다.
- **유사 질문 유추**
  - 질문을 단어(토큰)로 쪼개 이전 질문과 겹치는 비율을 계산합니다.
  - 임계값(`MEMORY_SIMILARITY = 0.35`) 이상 겹치면 유사 질문으로 판단합니다.
  - 유사 질문이 있으면 그때의 답변을 `[이전 대화 기억]` 컨텍스트로 프롬프트에 포함해
    AI가 이전 답변을 참고해 일관되게 답하도록 합니다.
- **백엔드 API 불필요**
  - 서버 API 없이 프론트엔드만으로 동작합니다. (별도 설정 불필요)

#### 2. 확대(expand) 모드 전체 화면 변경 (`widget.css`)
- 데스크톱 확대 모드가 기존 `560px × 85vh`에서 **전체 화면(`100vw × 100dvh`)**을
  채우도록 변경했습니다. (`webmcp_openrouter/front/widget.css`와 동일하게 통일)

#### 3. 메모리 기능 테스트 페이지 추가 (`memory-test.html`)
- 백엔드 API 없이 로컬스토리지만 사용하는 메모리 기능을 검증하는 테스트 페이지를 추가했습니다.
- 테스트 항목: 저장, 유사 질문 유추, 컨텍스트 조립, 무관 질문 판단, localStorage 영속성

### 📁 변경 파일
- `webmcp-widget.js` — 메모리 모듈 추가, 버전 v1.1.0
- `widget.css` — 확대 모드 전체 화면, 버전 v1.1.0
- `memory-test.html` — 신규 (메모리 기능 테스트 페이지)
